# 보고서 렌더 점검 목록 (배포 전·양식 변경 시)

자동 검사: `python3 scripts/check-report-render.py 점검보고서.docx 점검보고서.pdf <PNG폴더>`
(PDF 는 `python3 scripts/docx-to-pdf.py 점검보고서.docx 점검보고서.pdf` 로 만든다. LibreOffice UNO 로 제목 책갈피·태그 PDF·문서 언어를 남기고, 숫자와 단위 사이 자동 간격을 끈다. 맑은 고딕이 없는 환경은 fontconfig 로 Noto Sans CJK KR 에 연결. 종료 코드 0 = 통과)

자동으로 보는 것
- [ ] 쪽번호 "N / 전체"가 모든 쪽에서 맞음
- [ ] 모든 쪽에 한글이 보이고 깨진 글자(U+FFFD) 없음, 한국어 글꼴 지정(맑은 고딕) 있음
- [ ] 빈 페이지 없음, 본문 영역(좌우 여백) 밖 글자 없음
- [ ] 캡처가 페이지 위·아래 경계에 걸리지 않음, 캡처 바로 아래 "그림 P-…" 설명이 같은 쪽에 있음
- [ ] 빈 표 칸 없음 (값이 없으면 "-")
- [ ] 머리글이 있는 표는 머리글 행 반복 설정(tblHeader)

눈으로 보는 것 (PNG 폴더의 contact-*.png → 이상한 쪽만 page-NN.png 확대)
- [ ] 표지 한 장에 상태 띠·기본 정보·읽는 방법·구성이 다 보이고 큰 빈 공간 없음
- [ ] 1장 결론 요약이 1~2쪽 안에서 끝나고, 상태별 표(기준·유형·위치·화면)와 우선 처리 5개가 보임
- [ ] 페이지를 넘는 표의 다음 쪽 맨 위에 머리글 행이 다시 나옴
- [ ] 캡처: 축소본(a)과 확대본(b)이 각각 설명과 붙어 있음, 빨간 번호 ①과 주황 테두리가 문제 요소에 있음, 원본 색을 덮어 칠하지 않음
- [ ] 캡처 설명에 캡처 ID·화면명·비식별 주소·선택자가 있음 (주소에 쿼리 값 없음)
- [ ] 상태가 색과 함께 글자([확정]/[자동 신호]/[확인 필요] 또는 상태 이름)로 구분됨
- [ ] 8장 한계와 유의사항, 부록 C 참고자료(KWCAG 2.2·WCAG-EM 2.0·Report Template) 있음, 마지막 문장 "…품질인증을 의미하지 않습니다"
- [ ] 실제 Word(맑은 고딕 설치 환경)에서 한 번 열어 글꼴·줄바꿈 확인 (이 환경의 렌더는 Noto Sans CJK 대체 글꼴)

문서 접근성 (07)
- [ ] PDF 카탈로그 /Lang (ko-KR), /StructTreeRoot(태그 PDF) 있음
- [ ] 책갈피가 1~3단계 제목으로 만들어짐
- [ ] 모든 그림(/Figure)에 /Alt 대체 텍스트
- [ ] "11 개"처럼 숫자와 단위가 벌어진 곳 없음
- [ ] 외부 공유 산출물에 테스트 계정 이메일 없음, 제출 정보 빈칸은 "초안: … 입력 필요"
