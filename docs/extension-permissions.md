# 크롬 확장 권한과 사용 목적 (웹스토어 제출·사용자 안내용)

| 권한 | 언제 요청 | 목적 | 허용하지 않으면 |
|---|---|---|---|
| activeTab | 설치 시 | 확장 아이콘을 누른 그 탭에서만 잠시 동작 | — |
| scripting | 설치 시 | 허용한 사이트에 검사 엔진을 넣어 접근성 규칙을 확인 | — |
| storage | 설치 시 | 서버 주소·연결 키·설정, 확인 대기 캡처(브라우저를 닫으면 사라짐) | — |
| sidePanel | 설치 시 | 사이드 패널 화면 | — |
| 사이트 접근 (사이트별) | "현재 사이트 허용"을 누를 때 | 그 사이트의 화면 구조를 읽어 검사 | 그 사이트는 검사하지 않음 |
| 모든 사이트 (`<all_urls>`) | "화면 캡처 허용"을 누를 때 | 크롬은 화면 캡처를 이 권한(또는 아이콘 클릭 직후)에만 허용 | 캡처 없이 검사 결과만 올림 |
| debugger | "Tab 키 검사"를 켤 때 | 실제 Tab 키를 눌러 초점 이동·키보드 함정 확인 (사용 중 "디버깅 중" 표시) | 키보드 항목은 점검자 확인으로 남음 |
| downloads | "결과 파일 저장"을 누를 때 | 인터넷이 막힌 PC 에서 결과를 파일로 저장 | 파일 저장 불가 |

수집하지 않는 것: 쿠키, 세션·인증 토큰, 페이지의 localStorage/sessionStorage, 입력칸에 적힌 값(캡처에서는 흐리게 가림), 숨은 입력값.
확인 후 올리기(기본 켬): 캡처는 사용자가 사이드 패널에서 보고 "올리기"를 누른 것만 서버로 보내며, "버리기"를 누르면 확장에서도 지워진다.
모든 권한은 크롬 확장 관리 화면이나 사이드 패널의 "허용 취소"로 언제든 되돌릴 수 있다.
